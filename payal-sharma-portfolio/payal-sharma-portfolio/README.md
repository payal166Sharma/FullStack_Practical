# Payal Sharma | Full Stack Developer Portfolio

Built with React 18 and Vite.

## Run locally
```bash
npm install
npm run dev        # opens http://localhost:5173
```

## Build for production
```bash
npm run build      # output goes to dist/
npm run preview    # preview the production build
```

## Customize
- Edit `src/data.js` for your name, email, links, skills, projects and experience.
- Edit `src/styles.css` for colors (CSS variables at the top) and layout.

## Deploy
Upload the `dist/` folder to Netlify, Vercel or GitHub Pages.
